# TASKFLOW - Evidencia GA7-220501096-AA3-EV01

## Descripción
Aplicación web para gestionar tareas mediante Java Servlets, JSP y MySQL.

## Tecnologías
- Java 17
- Apache Tomcat 10.1
- Maven
- MySQL
- JDBC
- JSP
- HTML

## Funcionalidades
- Registrar tareas.
- Consultar tareas.
- Actualizar tareas.
- Eliminar tareas.

## Base de datos
Nombre: taskflow_db

Tabla: tasks

## Ejecución
1. Configurar Java 17 y Maven.
2. Configurar la conexión MySQL.
3. Configurar la variable de entorno DB_PASSWORD.
4. Ejecutar mvn package.
5. Desplegar el archivo WAR en Apache Tomcat.
